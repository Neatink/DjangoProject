# 📖DjangoProject

Це тестовий проєкт, створений за допомогою Django — фреймворку для розробки веб-додатків на Python.

## 📌 Опис:

Цей проєкт реалізує базову структуру Django-ORM, маршрутами, шаблонами та адміністративною панеллю.

## 🚀 Як запустити:

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/Neatink/DjangoProject
   cd DjangoProject

2. Створіть та активуйте віртуальне середовище:
   ```bash
   python -m venv venv
   
   source venv/bin/activate   # для Linux/macOS
   venv\Scripts\activate      # для Windows

3. Застосуйте міграції:
   ```bash
   python manage.py migrate

4. Запустіть сервер:
   ```bash
   python manage.py runserver

5. Перейдіть до:
   ```bash
   http://127.0.0.1:8000/

## 🛠️ Технології:
    Python

    Django
